tituli.geometry

tituli.geometry¶

Boxes, anchors, safe areas and parametric paths — the coordinate vocabulary.

Two coordinate systems, deliberately:

  • normalised (x, y, w, h) in 0..1 of the frame, top-left origin — the resolution-independent form used by specs, by burns.salient_box and by the lacing body. This is what a request is written in.

  • pixel Box (x0, y0, x1, y1) floats — what layout and rendering compute in once a Frame size is known.

A Path is a curve you can lay glyphs along: point(s) and angle(s) by arc length. Constructors cover lines, arcs, waves, Béziers, polylines and SVG d strings, which is what lets a calligram be any shape rather than a hard-coded sine.

>>> b = Box(10, 20, 110, 70)
>>> b.width, b.height, b.center
(100, 50, (60.0, 45.0))
>>> Box.from_norm((0.25, 0.5, 0.5, 0.25), 1920, 1080)
Box(x0=480.0, y0=540.0, x1=1440.0, y1=810.0)
>>> p = Path.line((0, 0), (100, 0))
>>> p.length, p.point(50), p.angle(50)
(100.0, (50.0, 0.0), 0.0)

class tituli.geometry.Path(points)[source]¶

A polyline with an arc-length parameterisation.

Build one with the constructors (line(), arc(), wave(), bezier(), polyline(), from_svg(), from_function()) and query it by distance along the curve: point(s) and angle(s) (degrees, clockwise-positive on screen because y points down).
